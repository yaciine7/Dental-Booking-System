# SmileCare Dental Clinic

A modern, professional dental clinic website built with React (JSX) and plain CSS.

## Features

- Responsive design (desktop, tablet, mobile)
- Sticky navigation with mobile hamburger menu
- Hero, About, Services, Why Choose Us sections
- Frontend appointment booking form with validation
- Contact section with map placeholder
- Professional medical color palette

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for Production

```bash
npm run build
```
